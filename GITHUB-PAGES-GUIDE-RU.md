# Как опубликовать PRREACHER: 2K MMR EDITION на GitHub Pages

## 1. Подготовка

1. Скачай ZIP проекта и распакуй его.
2. Открой папку `prreacher-birthday-edition`.
3. Убедись, что внутри прямо лежат `index.html`, `app.js`, `style.css`, `ASSETS.md`, `README.md` и папка `design`. Не загружай ZIP вместо файлов.

## 2. Создание репозитория

1. Открой https://github.com/ и войди в аккаунт.
2. Нажми `+` → `New repository`.
3. Назови репозиторий `prreacher-birthday`.
4. Выбери `Public`, затем `Create repository`.

## 3. Загрузка файлов

1. В новом репозитории нажми `Add file` → `Upload files`.
2. Перетащи или выбери ВСЁ содержимое папки `prreacher-birthday-edition`.
3. Проверь, что `index.html` находится в корне репозитория, а не в дополнительной вложенной папке.
4. Нажми `Commit changes`.

## 4. Включение GitHub Pages

1. Открой вкладку `Settings` репозитория.
2. В боковом меню выбери `Pages`.
3. В `Build and deployment` установи `Source: Deploy from a branch`.
4. В `Branch` выбери `main`, а папку — `/(root)`.
5. Нажми `Save`.
6. Подожди завершения публикации. Статус можно посмотреть в `Actions` или в разделе `Pages`.

## 5. Адрес сайта

Если имя GitHub-аккаунта `MYNAME`, адрес будет:

`https://MYNAME.github.io/prreacher-birthday/`

Открой ссылку на телефоне и проверь главное меню, начало кампании, мини-игры, профиль, достижения и настройки. Прогресс сохраняется локально в браузере посетителя.

## 6. Если сайт показывает 404

- Проверь, что файл называется ровно `index.html` (маленькими буквами).
- Проверь, что он лежит в корне репозитория.
- Проверь `Settings` → `Pages`: `main` и `/(root)`.
- Подожди 2–5 минут после первого сохранения и обнови страницу.
- Если не помогло, открой `Actions` и посмотри, завершилась ли задача `pages build and deployment`.

## 7. Что уже связано с STRATZ

В профиле игры добавлена ссылка на публичный профиль prreacher: https://stratz.com/players/1786601890. Кнопка открывает его страницу в новой вкладке.

Автоматическая загрузка MMR, побед, матчей и любимых героев пока не выполняется. Для полноценной интеграции нужен STRATZ API token. Его нельзя помещать в `app.js` или любой другой файл публичного GitHub-репозитория: токен сможет увидеть любой посетитель. Для безопасной автоматизации потребуется серверная функция/бэкенд, который хранит токен в секретах и отдаёт сайту только нужные публичные данные.

## 8. Важно

Это статический сайт без аккаунтов и облачного сохранения. Каждый посетитель проходит игру со своим локальным прогрессом. Сайт — неофициальный фанатский проект и не связан с Valve или STRATZ.
