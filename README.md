# PRREACHER: 2K MMR EDITION

Интерактивный браузерный прототип поздравительной мини-игры для prreacher от Mashorka.

## Запуск

**Самый простой вариант:** распаковать архив и открыть `index.html` в современном браузере.

**Через локальный сервер (рекомендуется):**

```bash
cd PRREACHER-2K-MMR-EDITION
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Что уже работает

- Главное меню и навигация между разделами.
- Поиск матча с сообщениями и переходом к пику.
- Выбор Рики или Клинкза.
- Загрузка матча.
- Два 30-секундных испытания на реакцию с рекордами.
- Кинематографические объявления серий убийств.
- Тест из семи вопросов с подсчётом результата.
- Режим выживания с активными угрозами и уклонениями.
- Финальный босс с тремя фазами, полосой здоровья и боевыми сообщениями.
- Экран победы, открытие сундука, письмо и секретная комната.
- Профиль, достижения и настройки.
- Локальное сохранение прогресса, рекордов и настроек.
- Синтезированные звуковые эффекты и тихий атмосферный drone через Web Audio API.
- Адаптивная вёрстка для узких экранов и сенсорного управления.
- Секретный код `322` на клавиатуре.

## Управление

- Все действия выполняются мышью или касанием.
- На главной странице нажать `START GAME`.
- В испытаниях нажимать на появляющиеся цели.
- В Survival нажимать `УКЛОНИТЬСЯ`, когда появляется угроза.
- В бою с боссом использовать четыре кнопки способностей.
- Профиль, достижения и настройки доступны в верхней панели.

## Сохранение

Прогресс хранится в `localStorage` текущего браузера. Кнопка сброса находится в настройках. Если открыть сайт в другом браузере или на другом устройстве, сохранение автоматически не переносится.

## Что намеренно оставлено на следующий этап

- Оригинальные Idle-видео Рики и Клинкза: ссылки на страницы с файлами указаны в `ASSETS.md`; сами файлы пока не включены в архив.
- Финальные иллюстрации, 3D-модели и анимации героев. Сейчас используются стилизованные CSS-символы как временные заглушки, а не выдаются за оригинальные игровые модели.
- Профиль prreacher привязан: https://stratz.com/players/1786601890. В интерфейсе есть кнопка перехода в STRATZ и указан Steam Account ID. Автоматическое отображение MMR и матчевой статистики пока не подключено: для него нужен STRATZ API token и безопасный серверный посредник; хранить секретный токен в публичном JavaScript нельзя.
- Финальная авторская музыка и озвучка диктора. Сейчас есть процедурные звуковые сигналы и фоновый синтезированный тон.
- Дополнительные персональные истории для письма. Текущий текст — безопасный черновик без выдуманных общих воспоминаний.

## Техническая основа

Проект сейчас сделан на чистых HTML, CSS и JavaScript, без сборщика и обязательных npm-пакетов. Это позволяет быстро открыть и проверить прототип. Когда визуальная система и игровые механики будут утверждены, можно перенести проект на React + TypeScript + Vite, не меняя пользовательский сценарий.

## Проверка

- `node --check app.js` — синтаксическая проверка JavaScript.
- Проверить вручную переходы по всем этапам, мобильную ширину, настройки звука и сохранение после перезагрузки.

## Примечание

Неофициальный фанатский проект-поздравление. Не связан с Valve или Dota 2. Названия, персонажи и игровые материалы принадлежат соответствующим правообладателям.
