# Figma-importable screen concepts

The SVG files in this folder are editable vector screen concepts at 1920×1080. Import into Figma by dragging each SVG onto a canvas or using File → Place image. Text and vector shapes remain editable after import, although fonts may need substitution.

- `main-menu.svg` — landing screen / hero composition.
- `hero-select.svg` — Riki and Clinkz selection.
- `challenge.svg` — reaction mini-game HUD and arena.
- `boss-battle.svg` — final boss encounter and cinematic kill feed.
- `treasure-letter.svg` — Immortal Treasure reward screen.
- `player-profile.svg` — profile and STRATZ empty state.
- `achievements-settings.svg` — achievements and settings hub.

PNG preview copies are included alongside each SVG.

These are first-pass visual layouts, not a native `.fig` file. They use temporary abstract character silhouettes; original hero renders and animations are still pending asset clearance and integration.
