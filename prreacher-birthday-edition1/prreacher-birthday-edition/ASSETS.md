## Current motion system

- CSS character hover / idle motion.
- Canvas starfield with twinkling particles.
- Ambient light fields and subtle pointer aura.
- Screen transitions and scroll-triggered reveal.
- Panel light response to pointer position.
- Reaction targets, boss pulse, kill announcements and victory effects.
- Web Audio synthesized UI effects and a low-level ambient drone.
