# Публикация PRREACHER // 2K MMR EDITION через GitHub Pages

Инструкция для телефона и компьютера. Сайт уже статический: сервер, npm и установка библиотек не нужны.

## Вариант A. Первая публикация

### 1. Скачать и распаковать

1. Скачай архив `PRREACHER-2K-MMR-EDITION-CINEMATIC.zip`.
2. Распакуй его.
3. Открой папку `prreacher-birthday-edition`.
4. Убедись, что внутри видны `index.html`, `style.css`, `app.js` и папка `art`.

**Критически важно:** загружать нужно содержимое папки, а не сам ZIP и не саму папку как вложенную директорию. Файл `index.html` должен оказаться в корне GitHub-репозитория.

### 2. Создать репозиторий

1. Открой [github.com](https://github.com/) и войди в аккаунт.
2. Нажми `+` вверху справа → `New repository`.
3. Назови репозиторий `prreacher-birthday`.
4. Выбери `Public`.
5. Нажми `Create repository`.

### 3. Загрузить файлы

1. На странице репозитория нажми `Add file` → `Upload files`.
2. Выбери всё содержимое папки `prreacher-birthday-edition`.
3. Проверь, что среди загружаемых элементов есть `index.html`, `style.css`, `app.js` и целая папка `art`.
4. Пролистай страницу вниз.
5. В поле сообщения оставь `Add website files` и нажми `Commit changes`.

### 4. Включить GitHub Pages

1. Открой вкладку `Settings` репозитория.
2. В левом меню найди `Pages`.
3. В `Build and deployment` выбери `Deploy from a branch`.
4. В `Branch` выбери `main`.
5. В папке выбери `/(root)`.
6. Нажми `Save`.
7. Открой вкладку `Actions` и дождись зелёного статуса `pages build and deployment`.

### 5. Открыть сайт

Адрес будет такого вида:

`https://ТВОЙ-ЛОГИН.github.io/prreacher-birthday/`

При первой публикации GitHub Pages может потребоваться несколько минут. Открой адрес в браузере и обнови страницу.

## Вариант B. Обновить уже опубликованный сайт

Этот вариант нужен, если старый сайт уже опубликован.

1. Скачай и распакуй новую версию архива.
2. Открой существующий репозиторий `prreacher-birthday` на GitHub.
3. Нажми `Add file` → `Upload files`.
4. Загрузить нужно всё содержимое новой папки `prreacher-birthday-edition`, включая `art`.
5. GitHub покажет файлы с теми же путями. Новые версии `index.html`, `style.css` и `app.js` должны заменить старые, а папка `art` добавится в репозиторий.
6. Нажми `Commit changes`.
7. Дождись зелёного статуса в `Actions` и обнови сайт.

Не создавай внутри репозитория дополнительную папку `prreacher-birthday-edition`. Правильный результат — `index.html` на верхнем уровне репозитория.

## Если GitHub Pages показывает 404

- Проверь, что файл называется ровно `index.html`.
- Убедись, что `index.html` лежит в корне репозитория.
- В `Settings` → `Pages` должны стоять `main` и `/(root)`.
- В `Actions` проверь, что последняя сборка завершилась успешно.
- После первого включения Pages подожди несколько минут и обнови страницу.

## Если главная открывается, но нет иллюстраций

Проверь, что папка `art` загружена в корень рядом с `index.html`. В ней должны быть:

- `art/riki-portrait.svg`
- `art/clinkz-portrait.svg`
- `art/last-feeder.svg`
- `art/favicon.svg`

Не переименовывай эти файлы и не меняй регистр букв.

## Как проверить сайт до публикации

На компьютере открой папку проекта и запусти:

```bash
python -m http.server 8000
```

Затем перейди на `http://localhost:8000`.

На Android можно открыть `index.html` в браузере, но для корректной проверки всех переходов надёжнее запустить локальный HTTP-сервер в Termux:

```bash
cd ~/storage/downloads/prreacher-birthday-edition
python -m http.server 8000
```

Открой в браузере `http://127.0.0.1:8000`.

## Что важно знать

- Прогресс хранится в браузере посетителя через `localStorage`, не в GitHub.
- STRATZ открывается по ссылке `https://stratz.com/players/1786601890`. Автоматическая загрузка MMR и матчей не включена: для неё нужен API и серверный посредник с секретом.
- Не клади API-токены, пароли и другие секреты в публичный репозиторий.
