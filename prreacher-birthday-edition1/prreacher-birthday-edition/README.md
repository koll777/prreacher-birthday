# PRREACHER // 2K MMR EDITION

Кинематографическое поздравительное браузерное приключение для prreacher от Mashorka. Проект сделан как самостоятельный статический сайт: без сборки, npm и backend для запуска.

## Быстрый запуск

Распакуй архив и открой `index.html` в современном браузере.

Для локального запуска через сервер:

```bash
cd prreacher-birthday-edition
python -m http.server 8000
```

Открой `http://localhost:8000`.

## Что внутри

- Кинематографическая главная сцена с авторскими SVG-иллюстрациями Riki и Clinkz.
- Анимированный звёздный фон, движущиеся световые пятна, параллакс-подсветка карточек, плавное появление экранов.
- Адаптивная шапка, навигация, индикатор сервера и управление звуком.
- Поиск матча с живыми сообщениями и переходом к выбору героя.
- Выбор Riki или Clinkz с отдельными карточками, описаниями и способностями.
- Два 30-секундных испытания на реакцию, рекорды и kill-streak эффекты.
- Тест из семи вопросов, режим выживания, финальный босс в три фазы.
- Экран победы, сундук, письмо от Mashorka и секретная комната с кодом `322`.
- Профиль игрока, локальная статистика, достижения и настройки.
- Синтезированные звуковые эффекты и атмосферный звуковой фон через Web Audio API.
- Локальное сохранение прогресса через `localStorage`.
- Мобильная раскладка и управление касанием.

## Управление

Нажми `НАЧАТЬ РЕЙД`, дождись поиска матча, выбери героя и проходи этапы. В реакционных испытаниях нажимай на появляющиеся цели. В Survival жми `УКЛОНИТЬСЯ`, когда активна угроза. В финальном бою используй способности против босса. Профиль, трофеи и настройки доступны в верхней навигации.

## Технические примечания

- Чистые HTML, CSS и JavaScript; сборщик не нужен.
- Внешний шрифт загружается с Google Fonts. При отсутствии сети сработают системные запасные шрифты.
- Иллюстрации героев — авторская стилизация в SVG, а не официальные игровые модели Valve.
- Нет аккаунтов, backend и облачного сохранения. Каждый браузер хранит свой прогресс локально.
- Проект является неофициальным фанатским поздравлением и не связан с Valve, Dota 2 или STRATZ.

## Проверка перед публикацией

```bash
node --check app.js
```

После загрузки на GitHub Pages проверь главную, выбор героев, оба испытания, тест, Survival, босса, сундук, письмо, профиль, достижения и настройки как на компьютере, так и на телефоне.
