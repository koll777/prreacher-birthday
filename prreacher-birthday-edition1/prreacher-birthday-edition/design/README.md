# Design assets

Папка `design` содержит ранние storyboard-макеты концепции. Они нужны как дополнительные референсы и могут импортироваться в Figma как SVG.

**Актуальный визуальный стиль опубликован в коде сайта:** `index.html`, `style.css`, `app.js` и оригинальные SVG-иллюстрации в `art/`. Для проверки итоговой композиции открой сайт локально или через GitHub Pages.

SVG-эскизы не являются нативным Figma-файлом `.fig`.
